# 环境搭建

当前设备为 Linux ARM64、NVIDIA GB10、Python 3.12.3，驱动支持 CUDA 13.0。本仓库按这台设备验证了 PyTorch `2.14.0+cu130`、torchvision `0.29.0` 和 Transformers `4.57.1`。

完整的当天操作顺序、数据准备、训练、恢复和推理见 [一天跑通教程](0.一天跑通.md)。

## 先认识三层环境

```text
系统 NVIDIA 驱动：让操作系统和 GPU 通信
项目 .venv：隔离 Python 与依赖版本
PyTorch CUDA 运行库：让张量算子在 GPU 上运行
```

驱动可用不等于当前 Python 已安装 torch；系统有其他 Python 也不等于 VS Code 选中了项目 `.venv`。先看 `sys.executable`、torch 版本和 CUDA 是否可用，再排查训练代码。

已配置的当前工作区直接进入下方检查，不需要反复重建虚拟环境：

```bash
.venv/bin/python -c "import sys, torch; print(sys.executable); print(torch.__version__); print(torch.cuda.is_available())"
.venv/bin/python scripts/lesson_lab.py --lesson tokenizer
```

前一条验证解释器与设备，后一条验证本地词表和依赖。无 CUDA 也可完成 CPU 教学小实验；GPU 主要用于后续更大的训练。全课程路线见 [学习路线](0.学习路线.md)。

## 使用已有 uv 和 Python

在仓库根目录执行：

```bash
uv venv .venv --python /usr/bin/python3
UV_CACHE_DIR="$PWD/.uv-cache" uv pip install \
  --python .venv/bin/python --index-url https://pypi.org/simple \
  -r requirements-aarch64.lock

.venv/bin/python scripts/smoke_test.py
.venv/bin/python -m unittest discover -s tests -v
bash trainer/run.sh
```

当前工作区已经配置好 `.venv`，可以直接运行 smoke test。系统驱动无需修改，项目所需 CUDA 运行库随 PyTorch wheel 安装。`.txt` 为直接依赖清单，`.lock` 为本机解析并验证的完整依赖锁定。

## 可选 Pixi

`pixi.toml` 已支持 `linux-aarch64` 和 `linux-64`。`pixi.lock` 由 Pixi 0.84.2 重新生成，使用新的 v7 锁文件格式：

```bash
pixi install --locked
pixi run check-gpu
pixi run smoke
pixi run test
pixi run demo
```

本机下载的 Pixi 可通过 `.tools/pixi` 调用；实际训练验证使用 uv 环境，Pixi 路线已完成依赖解析和锁文件更新。选用其中一条路线即可。

## 可选实验记录

训练参数 `--use_wandb` 在本项目中实际导入 SwanLab。uv 环境按需安装：

```bash
UV_CACHE_DIR="$PWD/.uv-cache" uv pip install \
  --python .venv/bin/python swanlab==0.6.8
```

Pixi 使用 `tracking` 环境。首次训练直接输出本地日志，完成闭环后再配置实验记录。
